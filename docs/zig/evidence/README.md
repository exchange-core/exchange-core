# Zig port evidence

This directory holds evidence that is useful for auditing or reproducing the
Java-to-Zig migration but is not implementation source.

- `EXCHANGE_API_*` files are generated by the serial gate. Their generators
  write both machine-readable JSON and human-readable Markdown here.
- dated benchmark reports and raw captures preserve the measurements behind
  historical capacity and SIMD claims.
- `JAVA_ZIG_PORT_SOURCE_*` manifests, archives, and checksum sidecars preserve
  reconstructable dirty-worktree snapshots used by the dated migration gates.

Do not place caches, ordinary compiler output, transient dumps, or new source
files here. Prefer regenerating derived evidence when its generator is part of
the repository; retain binary snapshots only when a manifest and checksum make
their audit purpose explicit.
