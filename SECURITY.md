# Security policy

Report vulnerabilities that affect `master` or a published release. Security fixes target `master`. See
[GitHub Releases](https://github.com/exchange-core/exchange-core/releases) for the versions that include a fix.

[Report a vulnerability privately](https://github.com/exchange-core/exchange-core/security/advisories/new).
Include the affected version or commit, the impact, and enough detail for the maintainers to reproduce the issue.
